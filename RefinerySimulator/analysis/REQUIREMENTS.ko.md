# Capstone 요건 충족 근거

## 유의사항 
구매 후보 탐색 자체를 선형계획(LP)라고 부르지 않습니다. LP는 별도의 운영 계획 모형입니다. 가상 실험 결과를 실제 기업 실적이나 인과효과로 소개하지 않습니다. 구현 여부와 현실 적용 가능성을 구분합니다.
