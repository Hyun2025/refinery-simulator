# 데이터와 가정 설명

## 요약

기본 계약은 휘발유·경유 각각 5,000배럴/일입니다. 화면에서 계약량을 바꾸면 기본 분석만 현재 입력으로 계산됩니다. 저장된 LP 표·작업량 한도 차트는 기준 계약량을 유지하며, 교육용 예시도 별개입니다.

이 프로젝트의 데이터는 실제 정유사의 관측 자료가 아니라, 정해진 가정으로 계산한 모의 운영 기록입니다. 숫자의 역할과 단위는 명확하지만 실제 공장에 맞게 추정한 계수는 아닙니다.

## 무엇이 한 행인가요?
기본 데이터 한 행은 특정 구매 조합과 조건에서 하루 동안 발생한 생산·판매·재고·비용의 기록입니다. 60일 기록을 모아 후보 하나의 이익과 계약 충족 여부를 계산합니다. 시나리오는 무작위 표본이 아니라 비교를 위해 정한 조건이며 발생확률은 부여하지 않았습니다.

## 주요 입력과 단위
|입력|설정과 의미|
|---|---|
|구매|총 100만 배럴, X·Y·Z 비율은 5% 단위|
|기간과 계약|60일, 휘발유·경유 각각 하루 5,000배럴|
|초기 원유|Y만 보유. 슬라이더 1일은 20,000배럴의 표시 단위|
|초기 제품|휘발유·경유 각각 10,000배럴|
|원유 X/Y/Z 가격|75−X 할인 / 78 / 80 USD/배럴|
|원유 X/Y/Z 운송비|3 / 2 / 1 USD/배럴|
|원유 X/Y/Z 처리비|5 / 4 / 4 USD/배럴|
|수율: 휘발유/경유/잔사유|X 25/35/40%, Y 30/45/25%, Z 35/40/25%|
|작업량 계수 X/Y/Z|1.4 / 1 / 0.9 가상 단위/배럴|
|추가 판매 기준가격|휘발유 95, 경유 105, 잔사유 55 USD/배럴|

입고는 기본 7일차부터 가능하며 X만 추가 지연을 적용합니다. 실제 입고량은 하루 하역 한도 100,000배럴과 원유 탱크 여유를 반영합니다. 자세한 순서와 비용은 화면의 조건 설명에서 확인할 수 있습니다.

## 가격 경로와 재고
가격 경로는 추가 판매 가격에만 적용합니다. 원유 구매가격과 계약 판매가격은 고정입니다. 세 제품에 같은 변동률을 곱하며 시작·마지막 값은 기준가격입니다. 직접 조정의 두 점은 날짜 순서를 유지하고 기준가격의 50~150% 범위에 있습니다.

구매대금은 0일차에 기록하므로 큰 지출이 나타나는 것이 정상입니다. 기초·기말 재고 평가는 현금 매출과 별도로 표시합니다. 수율 합계가 100%인 것은 가상의 부피 배분 규칙이며 실제 정유 공정의 질량 보존을 검증한 결과가 아닙니다.

## 계산할 수 없는 결과와 0의 차이
재고 0과 구매 비율 0은 유효한 값입니다. LP가 계약 조건을 만족하는 해를 찾지 못하면 null로 저장하고 화면에 계약 불가로 표시합니다. 이익 0으로 바꾸지 않습니다. 값이 없는 경우와 실제 값이 0인 경우를 구분해야 합니다.

## 문헌을 어떻게 사용했나요?
정유 계획 문헌은 구매·생산·재고를 연결하는 문제 구조를 참고하는 데 사용했습니다. 이 프로젝트의 수율·계수·규칙을 실제 회사가 사용한다는 근거는 아닙니다. 실제 원유 분석자료나 시장가격 표본을 사용하지 않았으며, 생성 기록으로 통계적 유의성이나 실제 인과효과를 주장하지 않습니다.
