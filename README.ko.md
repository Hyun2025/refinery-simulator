# CrudeFlow B — 실행과 수정 안내

## 먼저 읽는 요약
가상의 원유 구매 조합을 비교하는 정적 대시보드입니다. 기본 분석은 브라우저에서 현재 조건으로 계산합니다. LP 표와 작업량 한도 차트는 Python으로 미리 계산한 결과입니다. 가능 영역·이익선 차트는 별도의 교육용 예시입니다.
  
## 화면 실행과 배포
프로젝트 폴더에서 `python3 -m http.server 8000`을 실행하고 http://localhost:8000 을 여세요. 정적 호스팅에는 이 폴더의 파일과 `assets` 폴더를 함께 올립니다. 화면 실행에는 Python 계산 서버가 필요하지 않습니다. 기존 계산 검사는 `node test.js`로 실행합니다.

## 화면 읽는 순서
문제와 조건을 먼저 읽고, 분석 페이지의 좌우 버튼으로 판단·구매 구성비·가격·생산·손익·LP 비교를 살펴보세요. 우측 패널의 ‘지금 살펴보는 구매 조합’은 그래프와 손익의 표시 대상을 알려줍니다. 삼각 지도에서 후보를 직접 선택할 수 있지만 권고 카드와 기준 전략 비교는 계속 권고 결과를 보여줍니다.

삼각 지도 붉은 테두리는 최고 이익과의 차이가 최고 이익 절댓값의 1% 이내인 계약 충족 후보입니다. 별은 최고 이익과 $1 이내인 후보입니다. 보간 등고선은 계산한 점 사이를 추정한 안내이며 모든 비율을 계산했다는 뜻은 아닙니다.

좌측 문서 버튼에서 한국어·영어를 고르고 좌우 버튼으로 문서를 바꿉니다. X 또는 Escape로 닫습니다. 모바일에서는 하단 버튼으로 문서와 조건 조정 창을 엽니다.

## LP 결과 다시 계산하기
먼저 `python3 -m pip install -r analysis/requirements.txt`로 패키지를 설치합니다. 다음 명령을 프로젝트 폴더에서 순서대로 실행하세요.

1. `node analysis/export.js`: 기준과 비교 조건의 운영 기록을 생성합니다.
2. `python3 analysis/optimize.py`: 다섯 LP 비교실험 표를 생성합니다.
3. `python3 analysis/capacity_sweep.py`: 기준 입고 일정을 고정한 작업량 한도 실험을 생성합니다.

모형이나 기준 조건을 바꿨다면 결과 파일뿐 아니라 화면과 문서의 조건·결론도 함께 갱신하세요. LP 이익은 공통 재고 평가를 사용하므로 기본 손익 표와 직접 비교하지 않습니다.

## 무엇을 어디서 수정하나요?
|파일|수정할 내용|
|---|---|
|`index.html`|제목, 문제·조건, 차트 설명, LP 표 해석 안내|
|`help.js`|설정 옆 도움말|
|`app.js`, `benchmark.js`|계산 결과에 따라 바뀌는 안내와 표 제목|
|`lp-charts.js`|작업량 차트·교육용 차트의 설명과 조작|
|`engine.js`|기본 운영·손익 규칙|
|`analysis/optimize.py`|LP 변수·제약·목적함수|
|`analysis/capacity_sweep.py`|작업량 한도의 비교 범위|
|`analysis/*.ko.md`, `analysis/*.en.md`|한국어·영어 문서 원본|
|`reader-pages.js`|페이지 묶음과 문서 뷰어|
|`mobile.css`, `mobile.js`|모바일 배치와 조정 창|
|`theme.css`, `theme.js`|배경 배치, 색상, 테마 선택, 재계산 테두리 효과|

문서를 수정한 뒤 `python3 analysis/build_docs.py`를 실행하세요. 자동 생성 파일 `docs-data.js`는 직접 고치지 않습니다. 화면 요소 ID를 바꿀 때는 연결된 JavaScript도 수정해야 합니다. 대시보드는 직접 파일 다운로드 기능을 제공하지 않습니다.

## 테마와 모바일
기본은 밝은 테마이며 야간 테마로 바꿀 수 있습니다. 배경 이미지에는 애니메이션이 없습니다. 테두리 효과는 별도로 끌 수 있고, 기기의 동작 줄이기 설정에서도 생략됩니다. 테마는 계산 조건과 결과를 바꾸지 않습니다.

너비 900px 이하에서는 하단 버튼으로 조건 조정 창을 엽니다. 모든 브라우저·기기에서의 배치 검수는 완료하지 않았으므로 실제 배포 화면에서도 확인하세요.

## 해석의 범위
구매 후보는 231개, 기본 운영은 60일입니다. 실제 원유 분석자료를 사용하지 않았으며 품질·정비·체선료 등을 생략했습니다. LP는 미래 가격을 알고 입고 일정을 고정한 비교입니다. 보고서와 방법론 문서에서 결론의 적용 범위를 확인하세요.


## 하루 계약량 입력

우측 패널에서 휘발유·경유 계약량을 각각 입력합니다. 기본값은 5,000배럴/일이며 유효한 정수 입력마다 기본 분석을 다시 계산합니다. 빈 값·음수·소수·120,000 초과는 적용하지 않고 마지막 유효한 값을 유지합니다. 계약선과 60일 총량도 갱신됩니다. 추가 판매 한도와 초기 제품 재고는 바뀌지 않습니다. 저장된 LP 표·작업량 차트·보고서는 기준 계약량 5,000/5,000의 결과입니다. 교육용 예시는 독립적입니다.

코드의 기본값은 `engine.js`의 `defaults.gasolineContract`, `defaults.dieselContract`와 HTML 입력의 `value`를 맞춰 수정하세요. LP 계산은 내보낸 options의 계약량을 읽습니다. 기본값을 바꿨다면 README의 LP 재생성 명령과 보고서 갱신도 수행하세요.
